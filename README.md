# Predictive Analytics Using Historical Data

## Project Overview
This project predicts future sales using historical advertising data with a Linear Regression model.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## Dataset
Advertising dataset containing:
- TV Advertisement
- Radio Advertisement
- Newspaper Advertisement
- Sales

## Machine Learning Algorithm
Linear Regression

## Results
- Successfully trained the model.
- R² Score: 0.8567
- Predicted future sales based on advertising budgets.
